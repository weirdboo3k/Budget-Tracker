# 個人予算トラッカー (Personal Budget Tracker)

## 説明
これは個人の収入と支出を管理するためのシンプルなウェブアプリケーションです。
毎月のお金の流れを簡単に記録して、グラフで確認することができます。

## 機能

✅ 収入と支出を追加・編集・削除できます  
✅ カテゴリごとに分類して記録  
✅ グラフで収入と支出をビジュアル化  
✅ 年月日でフィルタリング  
✅ カテゴリで検索  
✅ CSVでエクスポート  
✅ ダークモード対応  
✅ データは自動保存される  

## 使い方

1. ブラウザで `index.html` を開く
2. タイプ（収入/支出）を選択する
3. 金額を入力する
4. カテゴリを選択する
5. 「追加」ボタンをクリック
6. 下のテーブルに取引が表示されます

### 編集・削除
- **編集**: テーブルの「編集」ボタンをクリック → フォームに入力が戻るので修正 → 「更新」ボタンをクリック
- **削除**: テーブルの「削除」ボタンをクリック → 確認画面で「OK」をクリック

### その他の機能
- **検索**: 検索ボックスにカテゴリ名を入力
- **フィルタ**: 年や月を選択して絞り込む
- **エクスポート**: 「CSVエクスポート」ボタンでダウンロード
- **リセット**: 「すべてリセット」で全データ削除（確認あり）
- **ダークモード**: 右上の月/太陽アイコンで切り替え
